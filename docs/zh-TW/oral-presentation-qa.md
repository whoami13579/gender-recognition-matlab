# 口頭報告問答

[逐頁講稿](oral-presentation-notes.md) · [操作指南](demo-and-oral-presentation.md)

1. **為什麼把 RGB 轉灰階？** 三通道改成一通道，保留明暗結構並降低特徵數與估計成本。代價是捨棄色彩訊息。本實驗固定同一前處理，沒有另外比較彩色的辨識效果。
2. **為什麼縮到 64 × 64？** 將 640 × 640 × 3 的訓練影像轉成 4,096 個特徵，控制記憶體和擬合成本。實作使用抗混疊雙線性縮放。64 是專案設定，解析度最佳值未另做搜尋。
3. **為什麼做 PCA 或 LDA？** 即使縮圖，4,096 維仍遠高於 160 個外折擬合樣本。降維讓特徵表示、共變異估計和分類運算更可控。
4. **PCA 和 Fisher LDA 的數學差異？** PCA 最大化所保留方向的總變異，無需標籤。Fisher LDA 以標籤計算平均差與類內散布，最大化類間分離相對類內變異的比值。
5. **二類 LDA 為何只有一維？** 二類間散布與 δδᵀ 成正比，δ 為類別平均差，外積的秩至多為 1。平均相同時沒有可辨識的 Fisher 方向，程式回報錯誤。
6. **LDA 為何要正則化？** 類內殘差的秩受樣本數限制，S_W 可能奇異。以殘差能量按特徵數縮放得到 α，加到對角線使求解更穩定。實作用薄 QR 和壓縮 SVD 保留平均差的零空間成分。
7. **PCA 為何用 economy SVD？** 對 N × D 中心化矩陣直接取右奇異向量，形狀受較小的維度限制。避免建立 D × D 像素共變異矩陣，也可從 σ² 直接取得解釋變異。
8. **為何採 Gaussian Bayes？** 在低維特徵上估計各類的高斯模型，結合經驗先驗形成連續後驗對數勝算，適合比較線性與二次判別的取捨。
9. **三種共變異有何區別？** Full 讓兩類各自取完整矩陣。Shared 彙整類內散布再除所有擬合樣本數。Diagonal 每類只保留各維變異，省下相關項，且每類仍可不同。
10. **如何穩定計算 Gaussian Bayes？** 使用 Cholesky 因子和三角解求 Mahalanobis 距離，log determinant 由因子對角線計算。對角模式以標準差直接計算。以兩類 log joint 的差取勝算，正分判 1，零分判 0。
11. **反向傳播如何運作？** 先算前向 logit 與穩定二元交叉熵。輸出誤差為 sigmoid(logit) − y，沿各層乘上權重轉置和 tanh 導數。小批梯度加上權重 L2，再用動量更新。
12. **為何 tanh 加單一 logit？** tanh 讓隱藏層表達非線性，並有簡單的導數。二元分類用單輸出即可，logit 可直接比較正負，也可保留給 ROC 排序。
13. **如何數分類器參數？** Bayes 數兩類平均、獨立先驗及各共變異的獨立值，對稱完整矩陣每個數 d(d+1)/2。MLP 數所有權重與偏差，單隱藏層為 (d+1)h + h+1。投影與標準化另列；MAT 位元組另受序列化影響。
14. **準確率與 AUC 差異？** 準確率基於 score > 0 的最終預測，依正確筆數比率計算。AUC 對應隨機正例得分排在負例前的機會，平手給一半權重。
15. **ROC 為何需要連續分數？** 逐步移動閾值才能觀察 FPR 與 TPR 的取捨。單一二元預測只給一個操作點。
16. **相同分數為何要一起處理？** 一個閾值會同時跨過這些樣本。分開處理將讓曲線與 AUC 依任意排序改變。
17. **五折 ROC 如何彙整？** 以各折 FPR 的聯集作為共同網格。各折保留垂直段的上下端，在相鄰段之間插值，再等權平均。因此保留原點與 FPR = 0 時的垂直跳升。表格的平均 AUC 是折 AUC 的平均，另有平均曲線的積分。
18. **為何用受試者 ID 分組？** 同一檔名 ID 的多張影像若跨擬合與驗證，模型可能受高度相似輸入影響。分組維持同折，並做類別分層。檔名衍生群組未經身分查證。
19. **什麼是資料洩漏？** 擬合或選參使用本應保留的輸入或標籤。例如先用全資料估 PCA 或 MLP 標準化，再切 CV。實作每折先分割，才估擬合狀態。
20. **為何採巢狀交叉驗證？** 內層四折選參，外折 40 張只估計整個選參流程的表現。獨立測試資料從設計到凍結都保留。
21. **四法為什麼都是 100%？** 實測顯示同一份課程資料、相同分組與該設定下達 100%，每折 AUC 也為 1。這組結果無法辨別影像條件、資料同質性或其他因素各自的影響。
22. **如何調查重複影像污染？** Issue #12 比對解碼像素的精確重複、標籤衝突和跨外折重疊，另用 16 × 16 單位灰階縮圖、RMSE ≤ 0.02 搜尋非完全相同的近重複。在 19,900 組訓練影像配對中均未發現候選；稽核範圍限於這些準則。
23. **為何完美 CV 無法保證獨立表現？** CV 重複取自同一訓練來源，外部資料可能有新的拍攝條件和分布。零折間 SD 只描述所觀察的折，無法估出獨立測試的不確定性。
24. **為何參數減少但準確率沒提高？** 外折分數已達上限。搜尋以平均 AUC、準確率、較少合計參數排序。表現相同時，較少參數的候選會勝出。最終 PCA + MLP 另用全訓練搜尋，20 維相較 10 維同 AUC 但平均準確率較高。
25. **為何暫採 LDA + Bayes？** 訓練端表現並列，模型只需 1 維和 4 個最終分類器參數。這是規模與訓練端證據的取捨；獨立資料會提供新的比較。
26. **為何分類器計時快很多？** 分類器從投影後特徵起算。完整推論還要對每張已載入影像做強度、灰階、縮放和投影，影像前處理可佔主要時間。兩種時間均排除磁碟 I/O。
27. **獨立結果為何待補？** 本機沒有課程保留目錄，既有嘗試標為 unavailable 且未評估任何方法。取得資料後驗證既有模型、測試規格與資料重疊，用同一批影像取得正式指標。
28. **如何存取已擬合模型？** 每條流程用版本化 MAT 存結構。Manifest 保存校驗碼，重載核對模型、設定、維度、參數量與持久化驗證結果。正式測試另驗證訓練內容索引。
29. **主要限制？** 資料量、可能同質、缺少獨立證據和身分查證，加上灰階縮放與模型假設。輸出對應課程二元標籤，外貌無法判定個人的性別認同。
30. **後續最優先的工作？** 用正式保留資料評估四個凍結模型。若另做研究，可用有授權且更具代表性的外部資料，事先定義分組、重複稽核和量測流程，再分析對成像條件的敏感度。
