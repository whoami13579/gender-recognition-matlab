# 性別辨識大挑戰（Gender Recognition Grand Challenge）專題說明

[English](../en/project-requirements.md) · [專案首頁](../../README.md)

依《PR_2026_專題說明文件_v1.pdf》（共 7 頁）編排。專題要求以原始文件為準。

## 一、專題背景與動機

本專題旨在讓同學透過實際的專題實作，整合並應用課堂所學之圖形識別相關知識與技術，包括 Bayesian Classifier、Principal Component Analysis（PCA）、Linear Discriminant Analysis（LDA）、Multilayer Perceptron（MLP）、Receiver Operating Characteristic（ROC）以及 Cross Validation 等。

本專題以「人臉影像性別辨識」作為實際應用問題，要求同學從影像資料中萃取適當的特徵，建立不同分類模型，並透過系統化的實驗與評估方法，比較不同特徵降維方法及分類器對性別辨識效能的影響。

透過本專題，同學能將課堂所學的理論應用於真實世界問題，也能學習如何設計實驗、分析實驗結果、比較不同方法的優缺點，並以口頭及書面報告方式呈現研究成果。

## 二、專題目標

本專題的主要目標為建立一套人臉影像性別辨識系統，並比較不同特徵降維方法與分類器組合之效能。

每組需實作以下四種分類方法。

1. PCA + Bayes Classifier
2. LDA + Bayes Classifier
3. PCA + MLP Classifier
4. LDA + MLP Classifier

針對上述四種方法，均需進行下列項目。

- 五折交叉驗證（5-fold Cross Validation）
- 計算分類準確率
- 繪製 ROC（Receiver Operating Characteristic）曲線
- 計算 AUC（Area Under the Curve）
- 特徵向量維度分析
- 模型參數量分析
- 訓練時間分析
- 推論時間分析

透過上述實驗，分析不同方法在性別辨識問題上的表現，並探討 PCA、LDA、Bayes Classifier 與 MLP Classifier 對分類結果及計算效率的影響。

## 三、影像資料

本專題提供人臉影像資料，分為訓練資料集與測試資料集。

| 資料集 | 男性 | 女性 | 人臉影像總數 |
|---|---:|---:|---:|
| 訓練資料集 | 100 | 100 | 200 |
| 測試資料集 | 50 | 50 | 100 |

### （一）訓練資料集

訓練資料需用於建立分類模型，並透過五折交叉驗證評估模型效能。

### （二）測試資料集

測試資料集僅用於最終模型測試，不應參與模型訓練及交叉驗證，以驗證模型的泛化能力（generalization capability）。

## 四、程式語言與開發環境

本專題統一使用 **MATLAB**。

同學可依課堂所學及自身需求使用 MATLAB 所提供之相關函式或自行撰寫程式，但必須能夠清楚說明所使用的方法、參數設定及實驗流程。

## 五、程式功能要求

每組需完成一套可執行之性別辨識程式，至少包含以下功能。

### （一）訓練功能

程式應能讓使用者設定訓練資料集的路徑。系統讀取訓練資料後，分別利用以下四種方法進行分類。

1. PCA + Bayes Classifier
2. LDA + Bayes Classifier
3. PCA + MLP Classifier
4. LDA + MLP Classifier

每一種方法均須進行五折交叉驗證，並產生下列結果。

- 分類準確率
- ROC 曲線
- AUC 值
- 特徵向量維度
- 模型參數量
- 訓練時間
- 推論時間

### （二）測試功能

程式應能讓使用者設定測試資料集的路徑。利用訓練資料建立最終模型後，將模型應用於測試資料集，分別針對四種分類方法執行下列項目。

- 計算分類準確率
- 繪製 ROC 曲線
- 計算 AUC
- 計算推論時間

## 六、實驗與分析要求

本專題要求完成分類系統，並著重透過實驗分析不同方法之間的差異。報告至少應針對以下項目進行分析與討論。

1. **分類準確率（Accuracy）**

   比較四種方法在訓練資料交叉驗證的分類準確率，並討論造成差異的可能原因。
2. **ROC 曲線與 AUC**

   繪製四種方法的 ROC 曲線，並比較其 AUC 值，以分析不同分類器對男女兩類資料的辨識能力。
3. **特徵向量維度**

   比較 PCA 與 LDA 所產生之特徵向量維度，並討論特徵維度對分類效能及計算效率的影響。
4. **模型參數量**

   比較 Bayes Classifier 與 MLP Classifier 的模型參數量，並討論模型參數量與分類效能之間的關係。
5. **訓練時間**

   比較四種方法建立分類模型所需的訓練時間，並分析不同特徵降維方法與分類器對訓練成本的影響。
6. **推論時間**

   比較四種方法進行性別辨識所需的推論時間，並討論不同方法的計算效率。
7. **綜合比較**

   最後應綜合分類效能、模型參數量及計算效率，討論四種方法各自的優點與限制，並說明哪一種方法整體而言較適合本專題所設定的人臉性別辨識問題。

## 七、分組方式

本專題預計分為 15 組。每組人數將依實際修課人數決定，預計每組約 5–6 人。

各組應共同完成程式開發、實驗、結果分析、口頭報告及書面報告。

## 八、評量方式

| 評分項目 | 權重 |
|---|---:|
| 口頭報告與現場 Demo | 60% |
| 書面報告 | 30% |
| 測試集 AUC | 10% |

評量將涵蓋以下面向。

- 專題系統之完整性
- 方法實作之正確性
- 實驗設計之合理性
- 實驗結果之完整性
- 結果分析與討論之深度
- 對所使用方法之理解程度
- 現場 Demo 表現
- 口頭表達能力
- 書面報告之完整性與專業性

## 九、口頭報告內容

口頭報告應至少包含以下內容。

1. **簡介**
   - 專題背景與目標
2. **方法介紹**
   - 系統流程圖
   - 重要參數設定
3. **實驗結果與分析**

   比較四種方法的下列項目，並針對實驗結果進行分析與討論。
   - 分類準確率
   - ROC 曲線
   - AUC
   - 特徵向量維度
   - 模型參數量
   - 訓練時間
   - 推論時間
4. **現場 Demo**

   現場展示性別辨識系統之實際執行結果。
5. **結論**

   整理本專題之主要發現，並說明四種方法的優缺點及整體比較結果。
6. **參考文獻**

   列出專題製作過程中所參考之論文、書籍及其他資料來源。

- ROC 曲線

完成本專題後，各組應具備以下成果。
