## Build on Windows

Use desktop Microsoft PowerPoint, Windows PowerShell, and Microsoft JhengHei for Chinese text. From the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File docs/presentation/build.ps1 -Render
```

The build reads the checked-in text and safe aggregate data. It writes the editable PPTX, PDF, speaker notes and optional slide renders under the ignored `results/presentation/` directory. Open the PPTX to edit it in PowerPoint. Edit the JSON and notes and rebuild if the changes should be reproducible. The PDF is the offline visual fallback.

## Evidence

The snapshot uses the Issue #11 baseline and nested runs from `91c6d5e` and the Issue #12 final fit from `984e14d`. The baseline is the documented run whose pipeline fit for PCA + Bayes was 506.23 ms. All eight saved mean ROC curves followed the same measured geometry. The editable charts retain the vertices and omit only collinear grid points. They use no individual raw scores, labels, images, or ROC thresholds.

For each method, the arrays in `evidence.json` are ordered as follows.

- `baseline` and `nested` contain mean accuracy and sample SD, mean AUC and sample SD, features, classifier parameters, classifier fit ms, complete fit ms, classifier batch inference ms, and complete batch inference ms.
- `final` contains features, projection, normalization, classifier parameters, combined parameters, classifier fit ms, complete fit ms, and MAT bytes.

Use `run_demo("results", ...)`, `run_demo("models", ...)`, and `run_demo("figures", ...)` with explicit selectors to verify the snapshot against local aggregates. The editable ROC drawing and slide wording describe the verified coincident curves and current pending status. Revisit them if the underlying evidence changes. Figures regenerated by MATLAB stay under the local demo output and can be opened independently during the demonstration.
